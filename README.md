# sing-box-extended Installer для OpenWrt

Интерактивный установщик и обновлятор [sing-box-extended](https://github.com/shtorm-7/sing-box-extended) для OpenWrt.

Скрипт скачивает выбранный стабильный релиз из GitHub Releases и заменяет бинарник:

```text
/usr/bin/sing-box
```

Конфигурацию Podkop и конфигурационные файлы sing-box скрипт не изменяет.

## Что делает скрипт

- получает список последних стабильных релизов upstream;
- исключает версии с метками `rc`, `beta` и `alpha`;
- предлагает выбрать один из десяти найденных стабильных релизов;
- определяет архитектуру устройства и скачивает соответствующий архив;
- поддерживает `curl` или `wget`;
- автоматически использует сервис `podkop`, если найден `/opt/etc/init.d/podkop` или `/etc/init.d/podkop`, иначе — сервис `sing-box`;
- создаёт сжатую rollback-копию текущего бинарника;
- проверяет архив и наличие бинарника внутри него;
- извлекает `sing-box` потоково непосредственно в `/usr/bin/sing-box`, не создавая второй распакованный бинарник в `/tmp`;
- проверяет запуск нового бинарника и соответствие выбранной версии;
- автоматически восстанавливает предыдущую версию при ошибке установки или запуска.

Если текущий `sing-box` был запущен до обновления, после старта сервиса скрипт ожидает его появления до 90 секунд. В течение этого времени можно проверить состояние Podkop через веб-интерфейс роутера. Чтобы отменить автоматический rollback и оставить новую версию для диагностики, введите `n` и нажмите Enter. Если ничего не вводить, при отсутствии процесса через 90 секунд будет восстановлена предыдущая версия.

## Использование

### Запуск через `wget`

```sh
sh <(wget -O - https://github.com/Nocturnal-ru/OpenWRT-sing-box-extended/raw/refs/heads/main/install.sh)
```

### Запуск через `curl`

```sh
sh <(curl -fsSL https://github.com/Nocturnal-ru/OpenWRT-sing-box-extended/raw/refs/heads/main/install.sh)
```

### Скачивание и ручной запуск

```sh
wget -O /tmp/sing-box-install.sh \
  https://github.com/Nocturnal-ru/OpenWRT-sing-box-extended/raw/refs/heads/main/install.sh
sh /tmp/sing-box-install.sh
```

Не рекомендуется запускать скрипт через обычный конвейер `wget ... | sh`: скрипту нужен стандартный ввод для выбора версии, каталога и возможного отказа от rollback.

После запуска:

1. выберите номер нужного релиза;
2. выберите каталог для временных файлов;
3. для устройств с небольшим overlay обычно выбирайте `/tmp`;
4. во время ожидания запуска при необходимости проверьте Podkop в веб-интерфейсе.

Выбор той же версии, которая уже установлена, выполняет переустановку.

## Временные файлы и место на диске

Скрипт предлагает два варианта:

```text
1) /tmp   — tmpfs/RAM
2) $HOME — flash/overlay
```

В выбранном каталоге временно находятся:

```text
sing-box-latest.tar.gz       скачанный архив
sing-box.rollback.gz         сжатая копия старого бинарника
```

При выборе `/tmp` архив и rollback-копия не требуют места на overlay. Сам новый бинарник записывается сразу в `/usr/bin/sing-box` после удаления старого файла.

Для роутеров с небольшим overlay рекомендуется `/tmp`. Вариант `$HOME` может завершиться ошибкой из-за нехватки flash — в этом случае старый бинарник не удаляется, если подготовительные операции не завершились успешно.

После успешной установки временная директория удаляется автоматически.

## Rollback и ручная диагностика

При сбое после начала замены скрипт автоматически:

1. останавливает сервис;
2. удаляет повреждённый или неработающий новый бинарник;
3. распаковывает старый бинарник из rollback-копии;
4. выставляет права `0755`;
5. снова запускает сервис.

Если во время 90-секундного ожидания ввести `n`, архив удаляется для освобождения RAM, а rollback-копия сохраняется до перезагрузки роутера. Скрипт выведет команды ручного восстановления. Для стандартного выбора `/tmp` они имеют вид:

```sh
service podkop stop
rm -f /usr/bin/sing-box
gzip -dc /tmp/sing-box-install/sing-box.rollback.gz > /usr/bin/sing-box
chmod 0755 /usr/bin/sing-box
service podkop start
```

Если выбран `$HOME`, путь к rollback-копии будет `$HOME/sing-box-install_tmp/sing-box.rollback.gz`.

Rollback-копия находится в `/tmp` и исчезнет после перезагрузки роутера. Не перезагружайте роутер, пока не завершили диагностику или ручное восстановление.

## Проверка после обновления

```sh
sing-box version
pidof sing-box
service podkop status
df -h /tmp /overlay
```

При проблемах с запуском полезны логи OpenWrt:

```sh
logread | grep -E 'podkop|sing-box' | tail -n 100
```

Проверка бинарника командой `sing-box version` не заменяет проверку конфигурации. Конфиг можно отдельно проверить подходящим бинарником:

```sh
sing-box check -c /путь/к/config.json
```

Предупреждение о deprecated-поле не обязательно означает невозможность запуска, но требует проверки изменений в конфигурации для используемой версии sing-box.

## Поддерживаемые архитектуры

| Значение `uname -m` | Суффикс архива |
|---|---|
| `aarch64` | `arm64` |
| `armv7*` | `armv7` |
| `armv6*` | `armv6` |
| `x86_64` | `amd64` |
| `i386`, `i686` | `386` |
| `mips` | `mips-softfloat` |
| `mipsel`, `mipsle` | `mipsle-softfloat` |
| `mips64` | `mips64` |
| `mips64el`, `mips64le` | `mips64le` |
| `riscv64` | `riscv64` |
| `s390x` | `s390x` |

На OpenWrt значение `DISTRIB_ARCH` из `/etc/openwrt_release` используется для корректного определения MIPS-вариантов.

Например, для Xiaomi AX3000T:

```text
OpenWrt target: mediatek/filogic
OpenWrt arch:   aarch64_cortex-a53
uname -m:       aarch64
Архив:          linux-arm64.tar.gz
```

## Важные ограничения

### Это не пакетный менеджер

Скрипт напрямую заменяет `/usr/bin/sing-box` и не устанавливает пакет `sing-box-extended` через `opkg` или `apk`.

Если в системе уже установлен штатный пакет `sing-box`, `opkg status sing-box` может показывать его исходную версию, например `1.12.x`, тогда как команда:

```sh
sing-box version
```

показывает реально используемую extended-версию. Такое расхождение ожидаемо при ручной замене бинарника. Последующее обновление или переустановка штатного пакета может перезаписать `/usr/bin/sing-box`.

### Проверка TLS

Для работы в сетях с проблемами проверки сертификатов скрипт использует `curl --insecure` или `wget --no-check-certificate`. Это снижает защиту TLS от подмены. Если соединение с GitHub работает с корректной проверкой сертификата, для более строгой модели доверия эти параметры следует удалить из локальной копии скрипта.

### Конфигурация Podkop

Скрипт не редактирует конфигурацию Podkop и не мигрирует deprecated-поля sing-box. Совместимость конфигурации с новой версией ядра необходимо проверять отдельно.

## Требования

- OpenWrt с доступной командой `service`;
- `wget` или `curl`;
- `tar` с поддержкой извлечения в stdout через `-O`;
- `gzip`, `awk`, `grep`, `sed`, `pidof`;
- доступ к GitHub API и GitHub Releases;
- достаточное свободное место в выбранном каталоге для архива и rollback-копии.

## Источник sing-box-extended

Релизы скачиваются из официального upstream-репозитория:

https://github.com/shtorm-7/sing-box-extended

Репозиторий этого проекта содержит только установщик и обновляющую логику, а не копии бинарников.
